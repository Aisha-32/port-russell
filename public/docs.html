Port Russell API Documentation

Dashboard | Catways | Users | API Docs |

Authentication

Method Route Description
POST /login User login
GET /logout User logout

Users

Method Route Description
GET /users Get all users
GET /users/:email Get user by email
POST /users Create user
PUT /users/:email Update user
DELETE /users/:email Delete user

Catways

Method Route Description
GET /catways Get all catways
GET /catways/:id Get one catway
POST /catways Create catway
PUT /catways/:id Update catway state
DELETE /catways/:id Delete catway

Reservations

Method Route Description
GET /reservations Get reservations
POST /catways/:id/reservations Create reservation
PUT /catways/:id/reservations/:reservationId Update reservation
DELETE /catways/:id/reservations/:reservationId Delete reservation
